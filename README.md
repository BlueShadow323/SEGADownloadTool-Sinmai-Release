# SEGADownloadTool-Sinmai-Release
一个用于某八个按键的音乐游戏的神秘工具

支持GA/GB的差分包与增量包的下载，文件解密，ICF编辑，定时拉取等功能，支持简体中文，繁体中文，English，日本語

这个是我在路边捡的，不是我做的，如果我捡到了新版本会发release

如果有问题可以提Issues，我会写小纸条放在路边如果被作者捡到了就会处理

我没有源码，如果你是超高技术力的话可以试试自己逆向，据我所知他是WPF应用
